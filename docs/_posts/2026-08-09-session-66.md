# There is an Engineering Competition

Honestly, this would hae been a deliberate nerd-snipe of Rusty if the antagonist paid any attention, but it wasn't.  Rusty built something cool - another Carrionette.  Oriana considers this copyright theft and extorts the Fartgun from Rusty.
